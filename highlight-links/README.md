# highlight-links

Outlines every external link on the active page in orange: a one-glance map of where a page
sends you. The change is visual only and disappears on reload.

Open a page in a browser tab, focus `highlight-links.ts`, and press `Cmd-Shift-R`.

Declares `// @permissions page-js`, because it changes the page, so the first run asks for
approval once.
See [this example in the docs](https://www.tranquillabs.dev/docs/example-highlight-links/).
