# 01 · Windows & Layout

Tranquil arranges everything inside one window using **docks**, **panes**, and **tabs**.
Let's shape the workspace. Try each step as you read.

## Docks — the panels around the edges

- **`Cmd-B`** — jump focus to the **file tree** on the left. Press it again to jump back to
  the editor. (This is how you move between the tree and your files without the mouse.)
- **`Cmd-Alt-B`** — toggle the **right dock** open/closed.
- **`Cmd-J`** — toggle the **bottom dock** open/closed.

The right and bottom docks are where things like the browser, search, and the vertical tab
list can live (you'll use them in the next lessons).

## Panes — split the editor

A **pane** holds a stack of tabs. Split the current pane to see two files side by side:

- **`Cmd-K` then `→`** — split to the **right** (arrow keys pick the direction: `↑ ↓ ← →`).
- Move focus between panes with **`Cmd-K Cmd-→`** (or `←`, `↑`, `↓`).

**Try it:** press `Cmd-K` then `→`. This document opens in a second pane on the right. Close
one copy with `Cmd-W` when you're done.

### Or just drag

You can also **drag a tab** to rearrange things — drop it in another pane, or into the
**right** or **bottom** dock to pin it alongside your work. (Browser tabs and file tabs both
work this way.)

## Tabs — move between open files

- **`Ctrl-Tab`** / **`Ctrl-Shift-Tab`** — cycle to the next / previous tab (in order, like a
  browser — no pop-up switcher).
- **`Cmd-1`** … **`Cmd-9`** — jump straight to the 1st … 9th tab.

### A vertical tab list

Prefer a browser-style vertical list of tabs instead of a horizontal bar? Open the command
palette (**`Cmd-Shift-P`**) and run **"Tabs: Toggle Vertical Tab List"**. It appears in the
right dock; run it again to hide it.

## Windows — more than one

- **File → New Window** — a fresh, empty window.
- **File → New Default Window** — a new window that opens *this guide's* project again.
  Handy for demos, or any time you want a clean copy of the examples.

Each window is **its own browser session** — you can be signed into the same website under
different accounts in two different windows, and they won't collide.

### Give a window its own color

To tell windows apart at a glance, assign one an accent color: **Window → Window Color →**
pick a color. It tints that window's status bar. Choose **Clear Color** to remove it.
