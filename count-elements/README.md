# count-elements

Counts how many of a tag are on the active page and shows the total as a notification.

Edit the selector in `querySelectorAll("img")` to count something else.

Open a page in a browser tab, focus `count-elements.ts`, and press `Cmd-Shift-R`.

Declares `// @permissions browser`, so the first run asks for approval once.
See the [Writing Automations guide](https://www.tranquillabs.dev/docs/writing-automations/).
