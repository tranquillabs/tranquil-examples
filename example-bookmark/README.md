# example-bookmark

Not an automation — a bookmark. Tranquil stores bookmarks as ordinary `.url` files in your project,
so they live in version control alongside everything else.

Double-click `Example.url` in the file tree to open it in a browser tab.

To make your own, open a page and press `Cmd-Shift-A`. See the
[Browser & Tabs guide](https://www.tranquillabs.dev/docs/guides/studio/browser/).
