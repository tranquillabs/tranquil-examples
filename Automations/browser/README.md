# browser/ — client automation scripts

Runnable in the Tranquil client. Open a web page in a browser tab, then focus one of these
`.js` files and press **`Cmd-Shift-R`** (the **Automations: Run in Webview** command,
`tranquil-automations:run-in-webview`). Available in scope: `tranquil`, `atom`, `require`,
`__dirname`, `__filename`.
